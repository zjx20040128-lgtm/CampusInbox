# CampusInbox：校园智能任务 Agent

CampusInbox 将学习通等来源的课程消息整理为待确认的学习任务，保留原文依据，辅助查看截止时间和任务进度。项目包含 Windows 桌面端、Web 页面与 Android 客户端。

## 电脑端启动

1. 安装 Python 3.10 或以上版本；学习通同步和桌面程序需要按相关组件的说明配置依赖。
2. 在 Windows 上双击 `start-desktop.cmd`；也可双击 `start.cmd` 使用 Web 页面。
3. 在程序中通过学习通官方页面登录，检查同步状态，再核对任务草稿。

首次运行使用本机独立数据。具体说明见 [Android 客户端](android/README.md)、[接口文档](docs/API.md) 和 [连接器说明](docs/CONNECTORS.md)。

## 当前范围

任务草稿、变更和补充需人工确认；学习通网页采集的完整性受页面、账号和网络影响。项目处于阶段开发与验收中，签到不会自动执行，作业也不会自动提交。

## 隐私与协作

不要提交真实消息、数据库、学习通会话、`.env`、令牌、截图或验收产物。每个成员应使用自己的账号与本机数据。真实场景和手机设备仍需各自验证。
