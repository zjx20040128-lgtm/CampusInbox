# CampusInbox：校园智能任务 Agent

CampusInbox 将学习通等来源的课程消息整理为待确认的学习任务，保留原文依据，辅助查看截止时间和任务进度。项目包含 Windows 桌面端、Web 页面与 Android 客户端。

## 组员首次运行：Windows 电脑

### 1. 获取项目

先接受仓库所有者发出的 GitHub 协作者邀请。打开仓库页面，点击 **Code → Download ZIP**，下载后解压；也可以使用 Git 克隆仓库。以下步骤均在解压或克隆后的项目根目录中操作。

### 2. 安装所需软件

- 安装 [Python](https://www.python.org/downloads/windows/) 3.10 或以上版本，安装时勾选 **Add Python to PATH**。
- 安装 [Node.js](https://nodejs.org/)，其中包含 npm，用于安装学习通同步依赖。
- 安装 Microsoft Edge，学习通同步会调用本机 Edge。
- 桌面程序首次启动时需要 Windows .NET Framework 自带的 C# 编译器；如提示找不到编译器，可先使用下面的网页启动方式。

安装后重新打开 PowerShell，运行 `python --version` 和 `npm --version`，确认两个命令都能正常显示版本。如果 Python 找不到，可重新安装并开启 PATH 选项。

### 3. 安装学习通同步依赖

在项目根目录打开 PowerShell，执行：

```powershell
npm install --prefix desktop-sync
```

这一步需要网络。Playwright 使用本机 Edge，无需另行下载 Playwright 浏览器。基础任务管理使用 Python 标准库，不需要模型 API Key；使用学习通同步时仍需完成上述依赖安装。

### 4. 启动并登录

1. 双击项目根目录的 **`start-desktop.cmd`**。首次启动会在本机编译桌面程序。
2. 在软件中打开“学习通同步”，使用**自己的学习通账号**扫描官方二维码并完成登录或验证。
3. 查看同步状态，再到消息收件箱核对草稿；确认后才会生成正式任务。
4. 关闭窗口后程序可能继续驻留系统托盘；需要完全退出时，在托盘菜单选择“退出软件”。

如果只想先体验网页任务管理，可双击 **`start.cmd`**，浏览器未自动打开时访问 `http://127.0.0.1:8765`。运行学习通同步仍需要步骤 2、3 的 Edge 和 Node.js 依赖。关闭启动窗口或按 `Ctrl+C` 可停止由该窗口启动的服务。

### 5. 首次使用与排查

- 仓库不包含个人数据库和学习通登录状态。每位组员首次运行都是独立的本机数据，需要自己登录和同步。
- 如果 `npm` 或 `python` 无法识别，先重新打开终端；仍不行时检查软件是否正确安装及 PATH 设置。
- 如果学习通无法同步，先检查网络、Edge、依赖安装和登录状态，并查看“学习通同步”页面的提示。页面显示部分读取或待重试时，需要检查原文，不能当作全部采集完成。
- 如果提示 8765 端口被占用，先关闭冲突程序；网页模式也可在项目目录运行 `powershell -ExecutionPolicy Bypass -File .\start.ps1 -Port 8877`，然后访问 `http://127.0.0.1:8877`。


## 安卓客户端

仓库包含 Android 源码，**不包含已构建的 APK**。需要通过 Android 开发环境另行构建后安装；运行和构建参考 [Android 客户端说明](android/README.md)。该文档中的旧 APK 下载链接和部分本机验收记录没有随源码快照上传。

更多说明：[接口文档](docs/API.md) · [连接器说明](docs/CONNECTORS.md)。

## 当前范围

任务草稿、变更和补充需人工确认；学习通网页采集的完整性受页面、账号和网络影响。项目处于阶段开发与验收中，签到不会自动执行，作业也不会自动提交。

## 隐私与协作

不要提交真实消息、数据库、学习通会话、`.env`、令牌、截图或验收产物。每个成员应使用自己的账号与本机数据。真实场景和手机设备仍需各自验证。
