# 学习通后台同步

首次在 CampusInbox 的“学习通同步”中扫码并确认登录。之后后台使用独立 Edge 会话读取聊天文字、课程通知和作业/考试列表，不需要手机伴侣或常驻学习通网页。电脑及 CampusInbox 服务必须保持运行。登录过期时重新扫码；任务继续走本地待确认草稿。

普通用户使用项目根目录的 `start-desktop.cmd`。它会构建或启动“CampusInbox 校园智能任务Agent”原生 Windows 程序，在软件窗口内显示官方登录二维码、同步状态和分类计数；关闭窗口后驻留系统托盘。旧的 `start-monitor.cmd` 与 `#sync` 页面仅作为 Web 调试入口保留。

桌面外壳只调用本机受保护接口，不解析学习通网页、不接触 Cookie、也不直接写 SQLite。登录页面、二维码、会话保存和消息读取仍由本目录的独立 worker 与 Python `DesktopSync` 负责。

## 依赖与启动

支持 Windows，需已安装 Microsoft Edge、Node.js 和 Playwright。当前电脑会自动使用已安装的 Codex bundled Node/Playwright。其他电脑在项目目录运行：

```powershell
npm install --prefix desktop-sync
.\start.cmd
```

可用 `CI_NODE` 指定 Node 可执行文件。Playwright 使用系统 Edge，不需要额外下载浏览器。PDF 优先使用可选 pypdf 提取文字；扫描页或未安装 pypdf 时使用 Windows 自带 PDF 渲染与 OCR。DOCX、UTF-8 文本使用本地提取器。

## 工作方式

`worker.cjs` 只启动本应用自己的浏览器，不读取已有浏览器配置。通过官方网页的可见聊天与通知 DOM 读取内容，无需学校开放平台接口。通知 DOM 慢加载时，使用同一会话请求该页的官方 `getNoticeDetail` 只读响应并核对 uuid/idCode；不接受身份不匹配的数据，不跟随重定向。二维码由官方 `#quickCode` 元素生成；扫码和任何额外验证均由本人完成。首次可用登录窗口完成验证，成功后转到后台会话。

Python 管理进程生命周期、文本队列、当前用户 DPAPI 加密会话和本地接收。登录 Cookie 只经进程管道传递，不进入 HTTP 状态、日志或明文文件。同步控制和二维码接口仅允许回环地址及主访问令牌；网页组件专用令牌无权调用。二进制附件提取后不持久化，只保存文字和官方固定下载链接。

聊天页面保持后台连接，消息连接断开会重新连接；空白消息区会等到内容出现或明确显示为空，避免把慢加载当成完整读取。聊天、课程通知和作业/考试分别在每轮完成后约一分钟检查，不相互阻塞。聊天每轮轮转当前已加载列表中的最多10个会话，向上加载旧消息并保留每次读取的记录；课程通知先滚动加载历史列表，再按游标每轮最多处理25条或运行90秒；作业/考试每轮扫描最多3门课程。游标保存在本机，重启后继续。页面、上下文或 Edge 关闭时会重建专用浏览器并复用加密会话。

历史加载有每轮预算；预算未覆盖完、页面失败或结构不明时，来源显示“部分待重试”及剩余数，不宣称完整。聊天图片、音视频和附件仍不在读取范围。作业/考试只提取官方列表中可见的任务和字段；未显示截止或提交方式时保留未知，不推断日期，也不自动打开未开始的考试。网络失败保留登录，以10/20/40/60秒间隔自动恢复；明确登录失效时才重新扫码。单条通知正文失败采用递增重试间隔，最长5分钟，其他通知继续；恢复同步先补传已保存文字队列。已接收消息按平台编号和任务内容版本去重。状态分别显示最近检查、最近收到消息、每个来源最近完整读取时间和待重试条数；部分读取不会刷新完整成功时间。读取可能将聊天或通知标为已读。

“暂停同步”会关闭独立浏览器并保留加密登录状态；重启服务会按此前启用状态恢复。Windows 用户或机器变化不能解密原会话，需重新扫码。

作业/考试列表的独立“剩余×小时×分钟”倒计时属于检查状态，不产生新消息版本。采集器计算版本时排除此类倒计时，服务端还按完整课程/班级/任务编号与实质内容去重；截止、要求、附件或提交状态变化仍保留为新来源。旧重复采集记录在备份后从消息列表折叠，数据库原文、任务关联和历史不删除；缺少完整编号时不按相同标题强行合并。

已接收的课程通知每隔至少10分钟分批复查，每轮最多5条，仍共用25条/90秒预算，避免迟加载图片永远漏收。复查时间和游标保存在本机；“重新检查”清除课程通知的跳过状态并重新排队，其他来源保持原去重机制。

课程通知中的 `p.ananas.chaoxing.com` 官方 PNG/JPG/BMP/WebP 图片会作为 `inline_image` 来源附件下载并本地 OCR；其他图片域与媒体保留缺口。固定下载域的说明附件支持 DOCX、PDF、TXT/MD 和图片。单批最多8 MiB，禁止跳转和向下载域转发 Cookie；二进制提取后不保存。原通知相同且附件身份一致时可补齐文字和追加迟发现的图片，保留原来源与确认边界。

PDF 最多30页；扫描 OCR 每次最多前10页、页面循环预算45秒，进程硬超时90秒。部分读取或失败会保留原文和缺口，不刷新来源完整成功时间，需拆分文件补充。“学习通同步 → 导出检查报告”提供不含正文/凭据的只读检查；报告不会把模拟测试当成真实账号或 Windows 通知验收。

只有标题的通知也会保存：详情页标题、发件人、发布时间与正文容器均已加载，且没有图片、音视频或未识别的嵌入内容时，后台等待至少5秒并确认内容稳定后保留空正文。消息详情明确显示“原通知正文为空”。正文尚未加载或仅有无法提取的媒体时仍保持待重试；仅有附件的通知保留附件清单。尚有待读取或待重试项时不会刷新来源的完整读取时间。

## 验证

`tests/test_desktop_sync.py` 验证生命周期、原文接收、去重、队列恢复、接口权限及 DPAPI。`scripts/test-desktop-chat.cjs` 检查多会话、备注名、标题晚于正文加载、空会话、短消息和恢复；`scripts/desktop-browser-check.cjs --chat` 启动独立临时数据库、模拟官方 DOM 与扫码确认，检查后台接收和新 worker 会话复用。模拟验收不等同于真实学习通账号验收。详见 [验证记录](../docs/verification/desktop-sync.md)。

`scripts/diagnose-desktop-notice.cjs` 从标准输入接收本应用解密后的专用会话，只输出失败详情页的元素存在情况和长度，不输出正文或凭据。`scripts/smoke-desktop-live.cjs` 对已运行的本机服务执行只读验收，检查两路同步状态、空正文消息详情提示和前端错误，结果存于 `docs/verification/desktop-live-smoke-result.json`。

`desktop-app/run-tests.ps1` 编译并验证桌面 API 客户端、状态映射、二维码校验、服务所有权、非阻塞控制器、单实例和托盘生命周期。正式 EXE 输出到 `artifacts/desktop/CampusInbox-Learning-Assistant.exe`。

扫码后网络中断修复证据见 [验证记录](../docs/verification/desktop-sync-recovery.md)。

聊天后台接入与真实补收结果见 [聊天同步验证](../docs/verification/background-chat-sync.md)。
