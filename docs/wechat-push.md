# 微信推送

在电脑端“手机连接 → 微信推送”配置 pushplus，无需手机常开网页、同一 Wi-Fi、公网域名或 Cloudflare 隧道。电脑及微信仍需联网并允许通知。

1. 打开配置卡片中的“获取 Token”，按 pushplus 官方页面完成微信绑定并取得用户或消息 Token。
2. 只在本机密码框填写 Token，勾选“开启微信推送”，点击“保存设置”。Token 经 Windows 当前用户 DPAPI 加密保存，不在状态接口、日志或页面回显，不必发到聊天。
3. 点击“发送测试”，核对微信是否实际收到。页面显示“pushplus 已受理”仅表示服务接收请求，不表示微信已送达；流水号可用于在 pushplus 检查发送记录。

首次开启及异常恢复不补发已有消息。启用后发送新通知、任务变更、截止提醒。任务只发送标题和截止摘要；普通学习通消息只提示有新消息，不发送聊天原文和附件。消息内容由第三方 pushplus 转发，受其账号、微信绑定、额度和通道政策影响。

开关与局域网提醒独立。取消勾选并保存可关闭；“清除 Token”会关闭并删除本机凭据。清除不会修改任务、原始消息或学习通登录。

明确的限流或暂时服务错误最多尝试三次，间隔至少 120 秒并增加等待时间；同一事件受理后不重复发送。网络超时、无效响应或发送中断后无法确认服务是否受理，因此标为“结果不明”并暂停自动发送，避免重复通知。检查微信和 pushplus 后，重新保存设置恢复；恢复时不会集中补发积压消息。

官方文档：https://pushplus.plus/doc/function/one.html
