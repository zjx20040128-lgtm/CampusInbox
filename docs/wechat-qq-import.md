# 微信、QQ文本导入

在电脑页面点击“导入通知”，选择“微信文本”或“QQ文本”，粘贴一条原消息，填写群名/会话；发件人、课程可选。发布时间填写原消息的北京时间，不清楚可留空。提取后在收件箱核对草稿，确认后才创建或更新任务。

本功能是用户主动粘贴导入，不登录微信/QQ账号，不监听电脑客户端，也不读取聊天历史。原有其他通知、学习通手动输入和文件转文字入口继续保留。

原文与平台、会话、发件人、真实发布时间分别保存。发布时间未知时，接收时刻仅用于内部记录，不充当发布时间，不推算“明天”或缺年份日期；仍可识别正文明确给出的完整日期。未知发布时间时采用规则提取，不向模型传入导入时刻作为锚点。

相同平台、会话、发件人、发布时间与正文重放幂等；平台或发送者不同的来源独立保留。既有任务的名称、课程和范围可靠匹配时复用原更新/冲突流程，始终需要确认；“实验报告”等笼统名称、不同群名或多个候选不强行匹配。跨平台群名不同的消息需人工核对，不能据此宣称已完成全自动跨平台关联。

主令牌本机接口：POST /api/connectors/chat/import，字段platform（wechat/qq）、text、conversation、sender、published_at（带时区ISO或null）、course、mode（rules/agent）。不接受未定义字段；没有增加公网接口。chat_import元信息随原消息保存，无数据库表迁移。
