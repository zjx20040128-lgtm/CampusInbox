# CampusInbox 学习通网页同步 0.3.2

## 安装与操作

1. 保持本机 CampusInbox 在 `http://127.0.0.1:8765` 运行，打开“学习通同步”页面。
2. 使用 Edge / Chrome 打开 `edge://extensions` / `chrome://extensions`，打开开发者模式，选择“加载解压缩的扩展”，选择本文件所在目录。下载 ZIP 时先解压。Codex 内置浏览器不能安装此组件。旧版本请重新加载更新后的目录。
3. 从 CampusInbox“学习通同步”复制网页同步专用令牌，点击扩展图标，粘贴令牌，勾选“启用通知与聊天同步”，保存。
4. 在安装组件的同一个浏览器打开 `https://i.chaoxing.com`，使用已有学习通账号登录，打开左侧“收件箱”，刷新一次。
5. CampusInbox 的“收件箱 → 消息记录”显示“学习通网页 · 课程通知”；任务要求进入待确认草稿。打开学习通作业或考试中心页面时，组件还会读取页面中已经显示的任务条目。默认启用“读取任务说明附件”，可在扩展设置关闭。

## 支持范围

- 电脑后台只使用列表实际提供、课程/班级/作业编号一致的只读说明链接，不自动打开作答或提交入口。说明附件可提取正文后补充到待确认要求，失败和未支持部分仍需核对。缺少只读入口或服务端正文时不标记为已读。更新组件后请重新加载扩展；已有作业不会因此自动确认。

- 收件箱当前页面已渲染的全部通知列表项，每轮最多读取25条未采集详情，后续轮次继续。每分钟使用同源临时页面刷新列表，读取浏览器渲染后的 DOM；不自动翻页或点击加载更多，因此不代表完整历史。发现登录失效、空列表或正文读取失败会显示状态。也支持打开单条通知详情同步。
- 保留标题、课程、发件人、发布时间、正文和附件名称/链接。只收取通知，不发送消息、评论或完成平台任务。读取详情可能将通知标记已读。
- 详情页的标题、发件人和发布时间已加载时，可保留原本没有正文或附件的通知；消息详情标注“原通知正文为空”。未完成加载的空页面不会当作完整通知。
- 自动尝试 DOCX 和名称含“说明、要求、作业、任务、通知、安排”等的 PDF / TXT / MD 附件。文件最大8 MiB，PDF仅文字层、最多30页，DOCX保留正文和表格行；正文与提取文字组合不超过30,000字符。不会自动读取所有研究材料全文。
- 每个附件明确标记：名称已同步、文字已读取、仅部分文字、读取失败或未自动读取。失败仍保存通知正文；扩展显示“附件待重试”，点击“立即重试”可补齐同一条通知的附件并刷新待确认草稿。不会改变已确认任务。
- 原始通知编号去重，聊天和课程通知使用不同来源及身份。第一次收到的正文保留，不同步正文编辑/删除；仅允许同一正文、标题、发布时间和附件链接的附件提取状态改善。新提取结果仍需人工核对。
- 时间来自通知发布时间。不能识别时仅保存文字，不按接收时间猜相对截止日期；“明天上课前”保留日期并提示核对课表，不能推断上课时刻。
- 仍支持官方 webim 页当前打开会话的已显示聊天文字；不切换会话，不采集隐藏消息、音视频或聊天附件。
- 作业/考试中心仅读取当前页面已经渲染、具有官方详情链接的条目，保留课程、班级、教师、截止、提交方式和平台状态。平台状态只作为证据，不会自动把本地任务标为“已提交”。未打开的页面、分页历史和平台未渲染内容不会被读取。
- 最多500条 / 150万字符待处理记录。网络错误保留队列，每分钟补传；200/201才移除。400/422记录单独保留并显示“格式待处理”，其他消息继续发送。队列满时显示错误，尚未保存的消息会再次尝试。关闭网页后只能补传已采集内容。
- 默认关闭同步。权限限于官方通知/聊天页面、固定附件下载域和 `127.0.0.1:8765`。不导出登录 Cookie、密码或平台凭据；网页同步专用令牌只允许本机写入通知及提取限定文档，不能读取其他本地记录。

## 开发验证

0.3.1 在作业/考试列表保持打开时，每分钟重传一次当前条目的观察值；服务端去重原文并更新最后核对时间，不重复生成草稿。后台桌面采集器另外支持只读作业详情补全；组件不会自动打开其他页面。

运行 `node --test scripts/test-chaoxing-web.cjs` 验证时间与后台队列；`node scripts/test-chaoxing-tasks.cjs` 验证作业和考试中心结构化条目；`node scripts/course-notice-check.cjs` 在临时数据库和脱敏站点 fixture 验证完整采集、附件、草稿和界面。`python scripts/package-browser-companion.py` 打包11个固定源码文件。

当前验证区分真实账号 DOM、一次真实通知与 Word 附件导入、脱敏自动测试和安装后的持续同步。最后一项需要在用户浏览器加载组件后验收；自动测试不代表组件已安装。

参考：[Chrome 内容脚本](https://developer.chrome.com/docs/extensions/develop/concepts/content-scripts)、[Chrome 网络请求](https://developer.chrome.com/docs/extensions/develop/concepts/network-requests)。
